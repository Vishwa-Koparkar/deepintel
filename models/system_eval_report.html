Evaluation Notes

The full system pipeline (ML + heuristic + threat intel fusion) was evaluated on a held-out test set with domain-level separation to prevent data leakage. The false negative rate measures how often truly malicious URLs were incorrectly labelled as safe — this is the most critical metric for a security tool and should be kept as low as possible. The false positive rate measures safe URLs incorrectly flagged, which affects usability. Both metrics are within acceptable range for a first-version system. Further improvement can be achieved by expanding the dataset and refining heuristic rules.
